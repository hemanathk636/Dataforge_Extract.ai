Knowledge Base

Frequently Asked Questions

Everything you need to know about Extract and autonomous scraping.

How does Extract compare directly to Browse AI, Apify, and Octoparse?

Unlike Browse AI, Apify, or Octoparse which meter every extracted row, enforce monthly credit limits (e.g. 2,000 credits for $48/mo), and hold your data hostage, Extract is 100% free, unmetered, and local-first. It runs directly on your machine or private server with zero third-party API dependencies, includes executive openpyxl Excel formatting with auto-fitted column widths, and provides a full Python SDK.

How does autonomous website change monitoring and alert triggers work?

In the Execution Hub's Website Monitoring tab, you can schedule background robots to inspect any webpage every 5 minutes, hourly, or daily. If a competitor drops their price, a product goes out of stock, or new listings appear, Extract compares the DOM hash and dispatches an instant email alert to your registered work email or triggers your custom webhook.

Can Extract handle dynamic JavaScript applications, infinite scroll, and multi-page pagination?

Yes! The underlying engine supports Playwright headless browser execution alongside fast BeautifulSoup heuristics. It handles JavaScript-rendered Single Page Applications (SPAs), automatically scrolls to trigger lazy-loaded AJAX requests, and navigates pagination buttons to capture complete multi-page catalogues without breaking.

How does Extract handle anti-bot shields, Cloudflare, and CAPTCHAs?

Extract camouflages scraper traffic with randomized modern TLS fingerprints, genuine device User-Agents (macOS, Windows, iOS, Android), randomized cursor delays, and stealth HTTP header ordering. This ensures target servers perceive incoming requests as authentic human visitors.

Why are the exported Excel spreadsheets styled better than raw CSV files?

Raw CSV files often lose leading zeros, cut off long text, and look unpresentable in executive meetings. Extract uses an automated openpyxl styler that injects navy blue header bands (#1E293B), bold white typography, subtle zebra row striping, currency alignment, and dynamically calculates and auto-fits every column width to prevent ### overflow errors.

Can I export data directly to Google Sheets, Airtable, or custom REST webhooks?

Yes. Every extraction generates both file deliverables (.xlsx, .csv) and a structured JSON API endpoint (/api/scrape, /api/robot/{type}). You can connect this endpoint to Zapier, Make.com, n8n, or directly pipe it into Google Sheets or PostgreSQL.

Is my extracted data and client information kept private?

100% private. Extract is built with a local-first philosophy. All parsing, document OCR, and spreadsheet generation occur locally on your environment. Your target URLs, extracted database rows, and client email addresses are never sent to external third-party telemetry servers.

Python Integration (Requests)

import requests

url = "http://127.0.0.1:8000/api/scrape"
payload = {
    "url": "https://books.toscrape.com/",
    "mode": "ecommerce",
    "max_items": 50
}

response = requests.post(url, json=payload)
data = response.json()

print(f"Captured {data['count']} items!")
print(f"Excel Download: {data['downloads']['excel']}")
