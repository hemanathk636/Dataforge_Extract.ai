# 🚀 DataForge AI Studio
### *High-Performance Web Extraction & PDF Automation Workbench*

A modern, production-grade automation suite designed to win freelance contracts and deliver executive-grade Excel/CSV deliverables to paying clients in under 5 minutes.

---

## 🌟 Key Features

1. **Intelligent Web Scraper**:
   - Heuristic DOM extraction for e-commerce (Titles, Prices, Ratings, Stock, Image URLs, Product Links).
   - Anti-bot User-Agent rotation and resilient network headers.
   - Extracts HTML tables and lead generation directories.

2. **Automated PDF Invoice & Receipt Parser**:
   - Multi-page table extraction using `pdfplumber`.
   - Automated detection of Invoice Numbers, Issue Dates, Taxes, Vendor Emails, and Grand Totals.

3. **Executive Excel Styler (`openpyxl`)**:
   - Automatically generates client-ready `.xlsx` spreadsheets with:
     - Sleek Slate header styling.
     - Alternating row zebra-striping.
     - Auto-fitted column widths (no clipped text).
     - Sticky frozen header panes for seamless scrolling.
     - Automatic column filtering.

4. **Modern Dark-Mode Web Dashboard**:
   - Responsive UI with live extraction status.
   - Real-time data table preview.
   - 1-Click Styled Excel and CSV export downloads.
   - Built-in Upwork, Fiverr, and Reddit client proposal templates.

---

## 🛠️ How to Launch

1. **Option A (One-Click):**
   Double-click [`start.bat`](start.bat).

2. **Option B (Terminal):**
   ```bash
   python run.py
   ```
   The dashboard will automatically open in your default web browser at `http://127.0.0.1:8000`.

## 💼 How to Use This to Earn Money ($50 - $250 per gig)

1. **Find a gig on Upwork / Reddit (`r/forhire`, `r/slavelabour`) / Fiverr**:
   - Look for requests like: *"Need product prices scraped from [Site] into Excel"*, or *"Convert 20 PDF invoices into a spreadsheet"*.
2. **Generate a free 5-item sample in 60 seconds**:
   - Paste the target URL into DataForge Studio and hit **Start Extract**.
   - Download the auto-styled `.xlsx` file.
3. **Send the Sample to the Client**:
   - Switch to the **Client Proposal Kit** tab in the dashboard.
   - Copy the ready-made pitch template and attach your sample Excel file.
4. **Get Hired & Deliver the Full Run**:
   - Once they see the professional Excel spreadsheet, they will hire you for the full dataset!
